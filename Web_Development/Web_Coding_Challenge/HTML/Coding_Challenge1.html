Introduction

Welcome to my profile page! I am learning HTML — the standard markup language for creating web pages. HTML describes the structure of a web page using elements represented by tags.
"HTML is the skeleton of the web. Without it, nothing exists."

Every HTML element can have attributes that provide additional information. Attributes are always placed in the opening tag and come in name/value pairs.
